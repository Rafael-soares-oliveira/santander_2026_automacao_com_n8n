# Bootcamp Santander 2026 Automação com N8N

Repositório para o bootcamp Santander 2026 Automação com N8N.

## Detalhes do bootcamp

Aprenda do zero como construir automações de processos com N8N, conectando Inteligência Artificial, workflows, integrações, APIs e webhooks em uma trilha prática que vai dos fundamentos até um projeto real de RPA com Python.
Entenda como funcionam Machine Learning, LLMs e IA Generativa para aplicar esses conceitos em automações, crie prompts mais estruturados para planejar fluxos com IA, dê os primeiros passos com N8N instalando, navegando e criando workflows simples, utilize nós padrão e integre serviços populares para automatizar processos, manipule dados e variáveis dentro dos fluxos e conecte sistemas externos por APIs e webhooks. O projeto final consolida tudo isso na construção de um processo de RPA com N8N e Python, combinando automação visual e desenvolvimento técnico em uma entrega prática para o portfólio.

### Atividades

1. Inteligência Artificial para Potencializar sua Aprendizagem
  - Fundamentos da IA Moderna
  - Potencializando Seus Estudos e Carreira com IA
  - Introdução à Engenharia de Prompts
  - Desafio: Treinando uma IA de Aprendizagem: Explore o poder do NotebookLM
2. Introdução a N8N e Workflows
  - Conceitos e Instalação
  - Navegação e Interface
  - Criação de Workflows Simples
3. Automatização de Processos com N8N
  - Utilizando Nós Padrão
  - Integração com Serviços Populares
  - Automatizando Processos
  - Desafio: Planejando Automações com N8N Usando Apenas Bons Prompts
4. Boas Práticas e Integrações com N8N
  - Manipulação de Dados e Variáveis
  - Uso de Webhooks e APIs
  - Desafio: Criando um Processo de RPA com N8N e Python
